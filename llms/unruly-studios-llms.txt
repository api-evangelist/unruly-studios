# Unruly Studios (Unruly Splats)

> Unruly Studios makes Unruly Splats — programmable, stompable floor buttons that teach kids to code through active, physical STEM play. Students use a tablet/computer app to program Splats to light up, make sounds, and score points, building games, dance competitions, and math activities they play with classmates. Founded 2015 in Boston by Bryanne Leeming; backed by Techstars, Amazon Alexa Fund, AT&T, eCoast Angels, and LearnLaunch.

This file is generated by the API Evangelist enrichment pipeline from the public Unruly surface. Unruly is primarily a consumer/education hardware + app company; its only machine API surface is an internal "Gamelocker" project store built on self-hosted GitLab.

## API surface
- [Gamelocker OpenID configuration](https://gamelocker.unruly-studios.com/.well-known/openid-configuration): GitLab OAuth 2.0 / OIDC discovery document for gamelocker.unruly-studios.com.
- Gamelocker REST API: GitLab v4 API at https://gamelocker.unruly-studios.com/api/v4 (projects, repository tree/files, commits). Used by the Splats app to store kids' coding "profiles" and game files as GitLab projects. Requires OAuth token; not a documented public developer API.
